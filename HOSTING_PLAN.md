# Схема размещения «Орбита Бот»

## Что размещаем

- GitHub Pages бесплатно хранит и показывает сайт по постоянной публичной ссылке.
- Timeweb запускает только серверную часть Flask и подключение к GigaChat.
- Секретный ключ GigaChat хранится только на Timeweb. В GitHub его не загружаем.

## Как сайт работает

- Пока Timeweb оплачен и сервер доступен, сайт получает настоящие ответы GigaChat.
- Если сервер Timeweb отключён или недоступен, сайт автоматически использует заранее подготовленные mock-ответы.
- В mock-режиме интерфейс и все инструменты продолжают работать, но ответы не создаются искусственным интеллектом.
- При повторном запуске Timeweb сайт автоматически возвращается к настоящему GigaChat.

## Оплата

- Платим только за период, когда необходим настоящий GigaChat.
- После сдачи проекта отключаем автопродление Timeweb.
- Бесплатная ссылка GitHub Pages и демонстрационный режим остаются доступными.

## Порядок дальнейшей работы

1. [Готово] Проверить текущий проект и существующие mock-ответы.
2. [Готово] Добавить автоматическое переключение между GigaChat и mock-режимом.
3. Подготовить проект к GitHub Pages, не меняя дизайн.
4. Создать репозиторий GitHub и опубликовать сайт.
5. Разместить Flask-сервер на Timeweb и сохранить там ключ GigaChat.
6. Подключить публичный сайт к адресу сервера и проверить всё по итоговой ссылке.
7. Проверить поведение при включённом и выключенном сервере Timeweb.
