# Орбита Бот: личная инструкция по проекту

Этот файл нужен, чтобы после долгого перерыва быстро вспомнить, где что находится и как снова запустить проект.

## Где хранится проект

### На компьютере

Основная папка проекта:

```text
C:\HTML_GAMES\BotV7_fixed
```

Главные файлы:

- `index.html` — страница сайта;
- `style.css` — оформление и анимации;
- `script.js` — работа интерфейса и отправка запросов боту;
- `background-frames.js` — кадры движения фоновой картинки;
- `back-desktop.webp` и `back-mobile.webp` — фон сайта;
- `orbital-drift.mp3` — музыка;
- `backend/app.py` — сервер Flask и подключение к GigaChat;
- `backend/prompts.py` — инструкции для шести инструментов;
- `backend/requirements.txt` — библиотеки Python;
- `backend/.env` — локальный секретный ключ GigaChat;
- `HOSTING_PLAN.md` — выбранная схема размещения сайта и бота.

### В GitHub

GitHub будет хранить код и бесплатно показывать сайт через GitHub Pages.

После создания репозитория записать сюда:

```text
Репозиторий: пока не создан
Публичная ссылка GitHub Pages: пока не создана
Логин GitHub: ____________________
```

Файл `backend/.env` и ключ GigaChat в GitHub загружать нельзя.

### На Timeweb

Timeweb будет запускать только сервер Flask, который обращается к GigaChat.

После размещения записать сюда:

```text
Адрес панели Timeweb: https://timeweb.com/
Название приложения: ____________________
Публичный адрес сервера: ____________________
Дата окончания оплаты: ____________________
Автопродление отключено: да / нет
```

Пароль Timeweb и сам ключ GigaChat здесь не записывать. Их следует хранить в менеджере паролей или в другом закрытом месте.

## Итоговая схема

- GitHub Pages хранит бесплатный сайт по постоянной ссылке.
- Timeweb запускает настоящий GigaChat, пока услуга оплачена.
- Если Timeweb недоступен, сайт переключается на подготовленные mock-ответы.
- После возобновления Timeweb сайт снова использует настоящий GigaChat.
- Ключ GigaChat всегда остаётся на сервере и не попадает в браузер или GitHub.

Подробный план находится в `HOSTING_PLAN.md`.

## Как запустить проект на своём компьютере

Открыть PowerShell и выполнить:

```powershell
cd C:\HTML_GAMES\BotV7_fixed
python -m pip install -r .\backend\requirements.txt
python .\backend\app.py
```

После запуска открыть в браузере:

```text
http://127.0.0.1:5000
```

Для остановки сервера нажать `Ctrl+C` в окне PowerShell.

Не следует открывать `index.html` двойным щелчком для проверки настоящего GigaChat: серверная часть в таком режиме не запускается.

## Как возобновить проект после паузы

1. Найти эту папку и открыть `README.md`.
2. Убедиться, что файл `backend/.env` на месте.
3. Проверить локальный запуск по инструкции выше.
4. Открыть репозиторий GitHub и проверить ссылку GitHub Pages.
5. Войти в Timeweb и снова запустить или заново развернуть сервер.
6. Добавить на Timeweb секретную переменную `GIGACHAT_AUTH_KEY`.
7. Указать в сайте актуальный публичный адрес сервера Timeweb.
8. Проверить настоящий ответ GigaChat.
9. Отключить сервер и убедиться, что включаются mock-ответы.

## Что сохранить перед отключением Timeweb

- код проекта должен быть на компьютере и в GitHub;
- в этом README должны быть записаны адрес репозитория, ссылка сайта и название приложения Timeweb;
- ключ GigaChat должен быть сохранён отдельно;
- автопродление и привязку карты нужно проверить в панели Timeweb;
- после отключения Timeweb сайт на GitHub Pages продолжает работать в демонстрационном режиме.
